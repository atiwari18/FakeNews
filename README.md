# Fake News Detection and Synthetic Claim Generation

## Project Definition

This project investigates how vulnerable misinformation detectors/classifiers are to synthetic adversarial claims using the [LIAR2 dataset](https://huggingface.co/datasets/chengxuphd/liar2) of fact-checked political claims from PolitiFact.

The pipeline has two independent sides that are evaluated against each other:

1. **Three classifiers** of increasing sophistication are trained on real LIAR2 data to detect fake claims.
2. **Two generative models** are trained on LIAR2 fake claims to produce synthetic misinformation.

The classifiers' training data is **never augmented** with synthetic claims. This is a deliberate design choice — the goal is to measure how exposed detectors trained purely on real data are to synthetic adversarial examples, not to study whether retraining closes that gap. The synthetic claims produced by both generators are used exclusively as an **adversarial evaluation set**.
 
The central question is: *how vulnerable are detectors trained on real misinformation to synthetic claims generated by models that have learned the same distribution?*

---

## Generative Methods
These are the two primary methods. Both generators are trained on **LIAR2 fake claims only** (binary label = FAKE), never on real/true claims. 

### Method 1 - LFM2.5-300M
An [LFM2-1.2B](https://www.liquid.ai/liquid-foundation-models) model fine-tuned with Low-Rank Adaptation (LoRA) on LIAR2 fake claims. The model learns to generate synthetic misinformation conditioned on structured inputs: label, speaker type, subject, and context.
 
LFM2 uses a novel hybrid architecture combining gated convolutions with grouped query attention, not a standard transformer, making this the first benchmark of this architecture on misinformation generation.
